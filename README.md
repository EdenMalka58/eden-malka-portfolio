# Eden Malka — Portfolio

Personal portfolio website for **Eden Malka**, Full Stack Developer and Computer Science graduate.  
The site showcases projects, skills, experience, and contact details — in both Hebrew and English.

## 🌐 Live Site

**https://edenmalka58.github.io/eden-malka-portfolio/**

## ✨ Features

- **Bilingual** — Switch between Hebrew and English
- **Responsive design** — Optimized for mobile, tablet, and desktop
- **Scroll animations** — Content reveals progressively as you scroll
- **Social links** — LinkedIn, GitHub, email, and phone

## 🛠️ Tech Stack

| Category | Technologies |
|----------|--------------|
| Frontend | React 19, TypeScript |
| Build | Vite 6 |
| Styling | CSS Modules, CSS Variables |
| Deploy | GitHub Pages |

## 📁 Project Structure

```
src/
├── components/     # UI components (Hero, Nav, Projects, Contact, etc.)
├── data/           # Static data (projects, skills, contact)
├── hooks/          # React hooks (useReveal)
├── i18n/           # Hebrew / English translations
└── styles/         # Global styles and design tokens
public/             # Favicon and static assets
```

## 🚀 Setup & Development

### Requirements

- Node.js 18+
- npm

### Local development

```bash
npm install
npm run dev
```

The site will be available at: http://localhost:5173

### Production build

```bash
npm run build
npm run preview
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

This command builds the site and publishes the `dist` folder to the `gh-pages` branch.
